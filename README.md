# Microsoft Fabric Solution Architect Lab

Hands-on Microsoft Fabric Solution Architect learning environment.

## Objective

Build a production-style Microsoft Fabric architecture using an automation-first approach.

## Environment

- Environment: DEV
- Fabric workspace: ws_fabric_architect_lab_dev
- Source control: GitHub
- Development branch: dev
- IDE: Visual Studio Code
- Automation: Fabric CLI, REST APIs, Git and CI/CD

## Learning Principles

- Microsoft Fabric official documentation is the primary source of truth.
- Prefer automation over repetitive manual configuration.
- Understand every manual operation before automating it.
- Document architecture decisions, alternatives, risks and revisit triggers.
- Test failures deliberately and diagnose them from evidence.
- Evaluate security, governance, scalability, performance and cost.
- Maintain evidence for each major lab.

## Repository Structure

- `config/` - Environment configuration
- `scripts/` - Automation scripts
- `docs/architecture/` - Architecture documentation
- `docs/decisions/` - Architecture Decision Records
- `docs/evidence/` - Lab evidence
- `docs/rca/` - Root Cause Analysis documents
